# teco-b2b-answereverything

用简洁图解和有来源的分析解释B2B销售问题，帮助理解客户处境、比较方案并确定下一步。

Copyright (c) 2026 tecoatwork

## 能做什么

客户开发、采购目的、采购委员会、FABMP价值、需求访谈、异议与沉默、成本比较、共同推进计划。支持内部分析版与客户展示版；回答末尾注明实际引用依据。

## 安装与使用

将整个仓库目录放入助手支持的技能目录，文件夹名保持 `teco-b2b-answereverything`。Codex常用目录为 `~/.codex/skills/`。不要求其他自建Skill、私人知识库、电子书或邮件账号。

```text
使用 teco-b2b-answereverything，解释客户不回复的可能原因和对策。
```

也可提供报价、客户原话或会议记录，请它绘制决策链、价值对比或下一步计划。品牌和产品资料由使用者提供；中文为默认语言，可指定其他语言。

## 参考资料与边界

内置21份资料的简短独立归纳与阅读边界，不附电子书、原文摘录库或下载渠道。仅使用摘要时会注明“依据选读摘要”；要求准确引文或更深分析时，需要合法原文或可核查的公开资料。PDF页序与EPUB定位依版本而异。

Storynomics条目来自Bookey摘要，不冒充原著。平台营销旧数据不作为当前事实。理论用于提出问题，不用于读心、保证成交或推断个人敏感属性。

本Skill只回答、图解和起草，不自动发送消息、更新CRM、改写知识库或发布内容。若生成HTML，仅在本地预览。

公开包完成名称、YAML、相对引用、文件存在性和私人信息扫描；未对通用版进行独立端到端客户测试。个人版曾用于对话示例，不代表销售效果验证。
